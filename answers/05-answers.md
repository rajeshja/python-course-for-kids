# Answer Key: Session 5: Patterns, Spirals, and Angles

Try the questions yourself first. Use this page only when you want to check your thinking.

### Question 1

Changing a number inside a loop lets the program create changing patterns such as growth, shrinking, or rotation.


## Core Challenge Rescue Path

Try the challenge yourself before reading these.

### Hint 1

Start with the square spiral and change only one number.

### Hint 2

Sketch several turns on paper before changing the growth amount.

### Worked example / minimal reference

The square-spiral starter is the minimal working reference. Your personal pattern is a modification, not a blank-page invention.

If your program is still broken, create a **fresh file**, copy the complete starter or checkpoint program from the lesson, and run it unchanged. Then compare your version with the known-good version one checkpoint at a time. This gives you a working reference without requiring you to guess which missing line to invent.

### Bug Hunt

Add a line inside the outer loop after the square is drawn, such as `size = size + 5`. The exact growth amount is your choice.
