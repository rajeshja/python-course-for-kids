# Answer Key: Session 4: Variables: Giving Things Names

Try the questions yourself first. Use this page only when you want to check your thinking.

### Question 1

A variable gives a value a reusable name.

### Question 2

Changing one variable can change every part of the program that uses that variable.


## Core Challenge Rescue Path

Try the challenge yourself before reading these.

### Hint 1

Change a value once and use its variable name everywhere else.

### Hint 2

Keep `input()` optional; it is not required for the Core Challenge.

### Worked example / minimal reference

Use `size`, `color`, and `angle` variables in the complete examples. Run first, then change one variable.

If your program is still broken, create a **fresh file**, copy the complete starter or checkpoint program from the lesson, and run it unchanged. Then compare your version with the known-good version one checkpoint at a time. This gives you a working reference without requiring you to guess which missing line to invent.

### Bug Hunt

Use `size = 100`, not `size == 100`. A single `=` assigns a value to a variable; `==` is used later for comparisons.
