# Answer Key: Session 1: Meet the Turtle

Try the questions yourself first. Use this page only when you want to check your thinking.

### Question 1

`forward(50)` moves the turtle 50 steps in its current direction.

### Question 2

The order matters because each instruction changes the turtle's position or direction before the next instruction runs.

### Question 3

`#` starts a comment; Python ignores the comment when executing the program.

### Worked example / minimal reference

Use the complete `lesson01.py` example in the lesson as your known-good starting point. Add only one movement or turn at a time.

If your program is still broken, create a **fresh file**, copy the complete starter or checkpoint program from the lesson, and run it unchanged. Then compare your version with the known-good version one checkpoint at a time. This gives you a working reference without requiring you to guess which missing line to invent.

### Bug Hunt
