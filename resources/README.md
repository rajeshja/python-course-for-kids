# Course assets

These are simple course-supplied assets. You do not need to download files from the internet.

## Pygame Zero

Copy the `pygame-zero/images` folder contents into the `images` folder of your Pygame Zero project.

Copy the `pygame-zero/sounds` folder contents into the `sounds` folder.

The supplied files include:

- `ball.png`
- `basket.png`
- `basket_left.png`
- `basket_right.png`
- `apple.png`
- `alien.png`
- `catch.wav`
- `miss.wav`
- `background.wav`

## Plain pygame

Copy the files from `pygame/assets` into an `assets` folder beside `main.py`.

These files are intentionally simple so that the course works without an internet search.

You may replace them with your own artwork later.
